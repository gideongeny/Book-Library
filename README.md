# 🌎 LIBRAWORLD - World-Class Digital Library

**LIBRAWORLD** is a premium, commercial-ready digital library platform that connects users with millions of books from across the globe. Built with a focus on high-end aesthetics, universal accessibility, and seamless performance.

![LIBRAWORLD Preview](public/logo.svg)

## ✨ Features

- **Global Book Search**: Integrated with the Open Library API to search millions of titles, authors, and subjects.
- **Premium UI/UX**: Ultra-modern design system featuring Glassmorphism, smooth animations, and a sophisticated dark mode.
- **Micro-Animations**: Experience fluid transitions and hover states that make the library feel alive.
- **Fully Responsive**: Optimized for every device, from mobile phones to high-resolution desktops.
- **Commercial Ready**: Professional structure, clean code, and attribution to its creator.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/gideongeny/book-library.git
   cd book-library
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

## 🛠 Tech Stack

- **Frontend**: React.js
- **Styling**: Vanilla CSS (Premium Custom Design System)
- **API**: Open Library API
- **Fonts**: Outfit & Inter (via Google Fonts)
- **Icons**: Custom SVG Branding
